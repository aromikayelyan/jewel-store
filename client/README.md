# MOAH Atelier — клиентское приложение

Новый фронтенд построен на React + Vite и оформлен в виде современной витрины ювелирного бренда. Интерфейс включает каталог
продукции, карточки товаров, блог с историями мастерской, страницу контактов и оформление заказа.

## Команды

```bash
npm install      # установить зависимости
npm run dev      # запустить приложение в режиме разработки (http://localhost:5173)
npm run build    # собрать production-версию
npm run preview  # локально просмотреть собранный билд
```

## Переменные окружения

| Название            | Описание                                               | Значение по умолчанию |
| ------------------- | ------------------------------------------------------ | --------------------- |
| `VITE_API_URL`      | Базовый URL REST API (продукты и блог)                 | `http://localhost:4700` |

## Стек и архитектура

- React 18 + React Router 6
- Глобальные данные загружаются в `AppDataProvider`
- Контекст `CartProvider` управляет состоянием корзины и синхронизирует его с `localStorage`
- Запросы к API выполняются через axios (`src/api/client.js`), при ошибках используется набор заглушек
- Дизайн построен на кастомной теме с эффектом стекла и градиентами без сторонних UI-библиотек

Структура исходников расположена в `src/`:

```
src/
 ├─ api/              # HTTP-клиент и методы получения данных
 ├─ components/       # Презентационные компоненты и layout
 ├─ context/          # Провайдеры данных и корзины
 ├─ data/             # Фолбэки при недоступности API
 ├─ pages/            # Страницы и маршруты
 ├─ utils/            # Утилиты форматирования
 └─ index.css         # Базовая тема и стили
```

## Дизайн и UX

- Основные цвета: глубокий тёмный фон, акценты золотом и сиренью
- Адаптивность для экранов от 360px, мобильное меню с полупрозрачным фоном
- Каталог включает фильтр по категории, поиску и диапазону цен
- Карточка товара показывает галерею, характеристики, рекомендуемые изделия
- Блог отображает сетку статей и одиночные публикации с галереей
- Формы (контакты, подписка, заказ) очищаются после отправки и готовы к интеграции с бэком

## Дополнительно

Стили вынесены в `index.css` и разбиты на секции (кнопки, карточки, страницы). При необходимости вы можете подключить
кастомный шрифт или заменить фоновые изображения, изменив соответствующие правила CSS.
